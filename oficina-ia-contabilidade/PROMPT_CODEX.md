# Prompt para Codex — Oficina IA Aplicada à Contabilidade

Você está implementando um projeto de oficina prática de IA aplicada à contabilidade.

Leia cuidadosamente:
- CONTEXTO_OFICINA.md
- REQUISITOS.md

e siga EXATAMENTE as definições destes arquivos.

---

# Objetivo principal

Construir artefatos simples, estáveis e didáticos para uma oficina de aproximadamente 1 hora.

O projeto NÃO é um sistema de produção.

---

# Prioridades

Prioridade máxima:
1. simplicidade;
2. estabilidade;
3. clareza pedagógica;
4. baixa fricção;
5. visualização clara dos resultados.

---

# Muito importante

NÃO:
- superengenheire;
- adicione complexidade desnecessária;
- crie abstrações excessivas;
- implemente integrações reais com ERPs;
- utilize bancos complexos;
- utilize autenticações complexas;
- utilize workflows gigantes.

---

# Os workflows devem ser

- pequenos;
- visuais;
- fáceis de explicar;
- fáceis de modificar;
- fáceis de entender depois da oficina.

---

# Sobre os workflows

Cada workflow deve:
- ter nodes bem nomeados;
- ter comentários quando necessário;
- usar prompts simples;
- retornar JSON estruturado;
- demonstrar claramente o papel do LLM.

---

# Sobre prompts

Os prompts devem:
- ser curtos;
- ser claros;
- ensinar boas práticas;
- demonstrar:
  - papel;
  - contexto;
  - tarefa;
  - formato de saída.

---

# Sobre os dados fictícios

Os dados devem:
- parecer reais;
- representar rotina contábil;
- conter:
  - PDFs;
  - XMLs;
  - e-mails;
  - pendências;
  - classificações.

Mas:
- SEM dados reais;
- SEM empresas reais;
- SEM CNPJs reais.

---

# Sobre o README

O README deve ser:
- extremamente prático;
- curto;
- orientado à execução;
- fácil para iniciantes.

---

# Sobre os slides

Os slides devem:
- ter pouco texto;
- ter narrativa clara;
- serem visuais;
- explicar:
  - IA;
  - prompts;
  - workflows;
  - automação;
  - impacto operacional.

---

# Estilo esperado

A oficina deve parecer:
- moderna;
- prática;
- próxima da realidade do escritório contábil.

Ela NÃO deve parecer:
- acadêmica;
- excessivamente técnica;
- focada em programação.

---

# Resultado esperado

Os participantes devem sair entendendo:

"LLMs transformam linguagem natural e documentos em dados estruturados acionáveis."

e

"IA não substitui o ERP. IA automatiza interpretação, organização e tomada inicial de decisão."
